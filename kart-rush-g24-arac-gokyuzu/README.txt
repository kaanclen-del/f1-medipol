F1 Medipol Kart Rush — Graphics 2.4 Car + Sky Upgrade

Ne değişir?
- Ana araç ve rakip araçların formu incelir, daha F1 tarzı görünür.
- Rakip araçların tekerlekleri kutu görünümünden çıkar.
- Gökyüzü daha katmanlı bulutlar, ufuk parıltısı ve yıldız detayları kazanır.

Kurulum:
1) ZIP'i proje klasörüne aç.
2) Proje ana klasöründe:
   node .\kart-rush-g24-arac-gokyuzu\INSTALL.cjs
3) Sonra:
   npm.cmd run build -- --webpack

Geri alma:
   node .\kart-rush-g24-arac-gokyuzu\RESTORE.cjs

Not:
- Bu paket yalnızca Graphics 2.3 üzerine kurulacak şekilde güvenlik kontrolü içerir.
- Sadece components/kart-rush/engine.ts dosyasını değiştirir.
