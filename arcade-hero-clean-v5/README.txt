F1 MEDIPOL ARCADE HERO CLEAN V5

Bu paket şunları yapar:
- Sarı çarpı atılan sol ve sağ mini kutuları kaldırır.
- OYUN BAŞLASIN içeriğini boş alanın içine düzgünce yerleştirir.
- Header'ı korur.
- Oyun kartlarını olduğu gibi bırakır.

Kurulum:
1) ZIP'i f1-medipol klasörüne aç.
2) Terminalde: node .\arcade-hero-clean-v5\INSTALL.cjs
3) Tarayıcıda Ctrl + Shift + R

Geri alma:
node .\arcade-hero-clean-v5\RESTORE.cjs
