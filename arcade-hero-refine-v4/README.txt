F1 MEDIPOL ARCADE HERO REFINE V4

Bu paket şunları yapar:
- Sağdaki ayrı hero paneli kaldırır.
- OYUN BAŞLASIN içeriğini soldaki hero alana taşır.
- Üç küçük kutu yerine tek geniş yatay dikdörtgen kullanır.
- Header'ı korur.

Kurulum:
1) ZIP'i f1-medipol klasörüne aç.
2) Terminalde: node .\arcade-hero-refine-v4\INSTALL.cjs
3) Tarayıcıda Ctrl + Shift + R

Geri alma:
node .\arcade-hero-refine-v4\RESTORE.cjs
