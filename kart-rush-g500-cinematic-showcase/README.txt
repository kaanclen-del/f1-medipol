F1 Medipol Kart Rush — Graphics 5.0 Cinematic Showcase

Kurulum:
  1) ZIP dosyasini projeye cikar.
  2) Proje kokunde:
       node .\kart-rush-g500-cinematic-showcase\INSTALL.cjs
  3) Sonra:
       npm.cmd run build -- --webpack

Bu paket G4.2.5 uzerine kurulur.
Icerik:
- Daha yogun tribün ve kalabalik meshleri
- Daha buyuk dalgalanan bayraklar
- Daha zengin gökyüzü ve gunduz aydinlatmasi
- Daha yogun yol/cevre geometri seviyesi
- Daha dogal asfalt tonu ve hafif kuru zemin parlamasi

Geri alma:
  node .\kart-rush-g500-cinematic-showcase\RESTORE.cjs
