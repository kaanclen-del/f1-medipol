KURULUM (VS CODE TERMINALİ, PROJE KÖKÜ)
1. ZIP'i Downloads klasörüne indir:

   Expand-Archive -LiteralPath $zip.FullName -DestinationPath "." -Force

2. Yerel test: npm.cmd run dev
   Açık temayı seç ve /live /predict /arcade /paddock /bildirimler /profile adreslerine bak.

3. Derleme kontrolü: npm.cmd run build

4. Derleme ve test başarılıysa:
