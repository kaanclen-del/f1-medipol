Kart Rush 3.1.1 Uyumluluk Düzeltmesi

Graphics 2.7 sürümünde KartRushClient.tsx içine eklenen ses lisansı notunu koruyarak Graphics 3.1 yağmur menüsü güncellemesini uygulayan kurucu.

Kurulum: node .\kart-rush-g31-uyumluluk-duzeltmesi\INSTALL.cjs
Geri alma: node .\kart-rush-g31-uyumluluk-duzeltmesi\RESTORE.cjs
Build: npm.cmd run build -- --webpack

Çevrimiçi yağmur seçimi için SUPABASE_WEATHER.sql dosyasını bir kez Supabase SQL Editor içinde çalıştır.

Kaynak sürümü bilinmiyorsa otomatik kurulum yapmaz ve mevcut SHA-256 değerini gösterir.
